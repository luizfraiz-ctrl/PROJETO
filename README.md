Sistema de Estacionamento

Projeto desenvolvido para gerenciar o funcionamento de um estacionamento, permitindo controlar usuários, veículos, vagas e os serviços oferecidos.

O sistema tem como objetivo facilitar o controle das vagas, registrar entradas e saídas de veículos e organizar as informações dos usuários e do estacionamento.

Principais funcionalidades
Cadastro e gerenciamento de usuários;
Cadastro e controle de veículos;
Controle de vagas disponíveis e ocupadas;
Registro de entrada e saída;
Gerenciamento de serviços;
Consulta das informações do estacionamento.

O projeto está sendo desenvolvido com foco em organização, praticidade, segurança e facilidade de uso.
